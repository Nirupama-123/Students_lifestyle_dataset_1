Students Lifestyle Dataset (Gen Z vs Millennials)
This repository contains cleaned and generated lifestyle datasets used for data visualization and comparison between Gen Z and Millennials.
The data includes daily activity patterns such as study hours, sleep hours, social time, physical activity, GPA, and stress levels.
The combined dataset is used in an interactive visualization project built using D3.js / VizHub / VS Code.
Files Included
1. genz_extended_18000.csv

Contains 18,000 Gen Z records

Original 2,000 rows + generated rows

Values kept realistic and based on the original Gen Z dataset

Generation label: "Gen Z"

2. millennials_18000.csv

Contains 18,000 Millennials records

Generated dataset following realistic adult lifestyle patterns

Higher extracurricular participation

Balanced sleep

Lower phone usage and stress compared to Gen Z

Generation label: "Millennials"

3. combined_student_lifestyle_36000.csv

Final merged dataset

36,000 total rows (18K Gen Z + 18K Millennials)

Used directly for visualization in your project

📊 Columns in the Dataset

All three datasets contain the same structure:

Column Name	Description
Student_ID	Unique ID for each student
Study_Hours_Per_Day	Daily study hours
Extracurricular_Hours_Per_Day	Time spent on extracurricular activities
Sleep_Hours_Per_Day	Hours of sleep per day
Social_Hours_Per_Day	Socializing time
Physical_Activity_Hours_Per_Day	Physical exercise hours
GPA	Grade Point Average
Stress_Level	Low / Moderate / High
Generation	Gen Z or Millennials
🎯 Purpose of This Dataset

This dataset is used to:

Compare lifestyle differences between Gen Z and Millennials

Analyze patterns in study habits, stress, sleep, and physical activity

Build an interactive dashboard showing both group trends

Support academic data visualization assignments
